4.2 指令的寻址方式

指令寻址

顺序寻址

(PC)+'1'→PC

跳跃寻址

由转移指令指出

数据寻址

隐含寻址

指令中隐含操作数的地址，如ACC

![image.png](第四章+指令系统+6f0ceb1f-b6e5-4fea-aad7-06749fdd2fbb/image.png)

优点：有利于缩短指令字长

缺点：需增加存储操作数或隐含地址的硬件

立即寻址

A就是操作数本身，一般采用补码

优点：指令执行阶段不访问主存

缺点：A的位数限制了立即数的范围

直接寻址

EA=A

![image.png](第四章+指令系统+6f0ceb1f-b6e5-4fea-aad7-06749fdd2fbb/image 1.png)

间接寻址

EA=(A）

![image.png](第四章+指令系统+6f0ceb1f-b6e5-4fea-aad7-06749fdd2fbb/image 2.png)

优点：扩大寻址范围；便于编制程序

缺点：指令执行阶段需要多次访存

寄存器寻址

$EA=R_i$

![image.png](第四章+指令系统+6f0ceb1f-b6e5-4fea-aad7-06749fdd2fbb/image 3.png)

优点：执行阶段不访问主存；指令字短且执行速度快

缺点：寄存器价格昂贵，数量有限

寄存器间接寻址

$EA=(R_i)$

![image.png](第四章+指令系统+6f0ceb1f-b6e5-4fea-aad7-06749fdd2fbb/image 4.png)

与一般间接寻址相比速度更快

相对寻址

EA=(PC)+A

![image.png](第四章+指令系统+6f0ceb1f-b6e5-4fea-aad7-06749fdd2fbb/image 5.png)

A是相对于PC所指地址的位移量

优点：一段代码在程序内浮动时不用更改跳转指令的地址码，广泛应用于转移指令

基址寻址

EA=(BR)+A

![image.png](第四章+指令系统+6f0ceb1f-b6e5-4fea-aad7-06749fdd2fbb/image 6.png)

程序运行前，CPU将BR的值修改为该程序的起始地址

BR作为基地址，A为偏移量

优点：便于（整个）程序浮动，方便多道程序并发运行

变址寻址

EA=(IX)+A

![image.png](第四章+指令系统+6f0ceb1f-b6e5-4fea-aad7-06749fdd2fbb/image 7.png)

IX的内容可由用户改变

IX作为偏移量，A作为基地址

优点：可以不断改变IX的内容，适合编制循环程序

堆栈寻址

操作数存放在堆栈中，隐含使用SP作为操作数地址

![image.png](第四章+指令系统+6f0ceb1f-b6e5-4fea-aad7-06749fdd2fbb/image 8.png)

堆栈是寄存器种一块特定的、按后进先出管理的存储区，SP存储在特定的寄存器中

硬堆栈：寄存器堆栈

软堆栈：从内存中划出一段区域做堆栈

4.4 CISC和RISC

CISC：Complex Instruction Set Computer

复杂、庞大

指令数目：>200

指令字长：不固定

可访存指令：不加限制

微程序控制

RISC：Reduced Instruction Set Computer

简单、精简

指令数目：>100

指令字长：定长

可访存指令：Load/Store指令

组合逻辑控制
